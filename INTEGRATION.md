## How the layers talk

```
Frontend  --(API request)-->  Backend  --(query)-->  Database
                                 |
                                 └--(calls)--> Integrations (payments, auth, email, maps)

All of the above runs inside → Server (hosting / the building)
```

Analogy: Frontend is the dining area, Backend is the kitchen, Database is the store room, Integrations is the waiter carrying orders in and out, and Server is the whole building it all runs in.
